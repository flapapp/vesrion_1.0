# PORU4 - Мобільний застосунок для пар

## 🎯 Огляд проекту

PORU4 - це інноваційний мобільний застосунок, створений для зміцнення зв'язків між парами через персоналізовані челенджі, щоденні заставки та інтерактивні сюрпризи.

## 📱 Створені файли

- **`index.html`** - Головна сторінка з вибором версій
- **`poru4-complete-mvp.html`** - Повнофункціональний MVP (РЕКОМЕНДОВАНИЙ)
- **`room-creation-guide.html`** - Покроковий гід створення кімнати

### 📋 Додаткові версії

- **`poru4-advanced.html`** - Розширена версія

### 📚 Документація

## 🎮 Як тестувати

### Швидкий старт:
1. Відкрийте `index.html` в браузері
2. Натисніть "Відкрити повний MVP"
3. Натисніть "Почати" та оберіть роль "ПАРТНЕР"
4. Введіть код: **ABC123**
5. Досліджуйте всі функції!

### Детальне тестування:
1. **Створювач**: Оберіть роль "СТВОРЮВАЧ" та створюйте челенджі
2. **Партнер**: Оберіть роль "ПАРТНЕР" та проходьте челенджі
3. **Покроковий гід**: Відкрийте `room-creation-guide.html` для детального розуміння

- **Анімації**: Плавні переходи та інтерактивні ефекти

PORU4 MVP повністю демонструє концепцію застосунку для пар з усіма ключовими функціями. Застосунок готовий до тестування та демонстрації потенційним користувачам та інвесторам.

**Головна перевага**: Гнучкість налаштувань - створювач може налаштовувати дні поступово, не втрачаючи контроль над процесом, а партнер завжди має що робити.
