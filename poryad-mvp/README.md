# Poryad - MVP Дизайн Варіанти

Це HTML прототипи для мобільного застосунку Poryad - платформи для створення персоналізованих челенджів для пар.

## 📱 Варіанти дизайну

### Варіант 1: Мінімалістичний
**Файли:** `variant_1_minimalist.html`, `constructor_variant_1.html`, `partner_variant_1.html`

**Особливості:**
- Чистий, мінімалістичний дизайн
- Градієнтні кольори (синій-фіолетовий)
- Прості форми та кнопки
- Фокус на функціональності

**Кольорова схема:**
- Основний: #667eea → #764ba2
- Акцент: #48bb78 (зелений для успіху)
- Фон: #f8fafc

### Варіант 2: Сучасний (Dark Mode)
**Файли:** `variant_2_modern.html`, `constructor_variant_2.html`, `partner_variant_2.html`

**Особливості:**
- Темна тема з неоновими акцентами
- Стеклянний ефект (backdrop-filter)
- Анімації та floating елементи
- Градієнти з яскравими кольорами

**Кольорова схема:**
- Основний: #ff6b6b → #4ecdc4 → #45b7d1
- Фон: #0f0f23 (темний)
- Акцент: неонові кольори

### Варіант 3: Теплий (Romantic)
**Файли:** `variant_3_warm.html`, `constructor_variant_3.html`, `partner_variant_3.html`

**Особливості:**
- Теплі, романтичні кольори
- Сердечки та sparkle анімації
- М'які форми та закруглення
- Емоційний підхід до дизайну

**Кольорова схема:**
- Основний: #ff6b6b → #ffa726 → #ff5722
- Фон: #ffecd2 → #fcb69f (теплі тони)
- Акцент: рожево-оранжеві градієнти

## 🎯 Основні екрани

### 1. Реєстрація/Авторизація
- Простий email/пароль або телефон
- Візуально привабливий дизайн
- Зрозумілі кнопки дій

### 2. Конструктор (Створювач)
- 4 покрокові кроки:
  1. Завантаження фото (7 на тиждень)
  2. Написання текстів (7 на тиждень)
  3. Створення челенджу
  4. Запрошення партнера
- Швидкі дії для зручності

### 3. Партнер (Учасник)
- Денна заставка з фото та текстом
- Інформація про челендж
- Календар з прогресом
- Кнопка "Слухати умови"

## 🚀 Наступні кроки

1. **Обрати варіант дизайну** - який стиль найбільше подобається?
2. **Деталізація функцій** - додати модальні вікна, форми створення челенджу
3. **Мобільна адаптація** - оптимізувати для мобільних пристроїв
4. **Інтерактивність** - додати JavaScript для функціональності
5. **Backend інтеграція** - підключити до сервера

## 💡 Рекомендації

- **Варіант 1** - для серйозної, професійної аудиторії
- **Варіант 2** - для молодої, технологічної аудиторії
- **Варіант 3** - для романтичної, емоційної аудиторії

Всі варіанти адаптовані для мобільних пристроїв та мають responsive дизайн.
