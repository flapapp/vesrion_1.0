# PORU4 - Мобільний застосунок для пар

## 📱 Опис

PORU4 - це інноваційний мобільний застосунок, створений для зміцнення зв'язків між парами через персоналізовані челенджі, щоденні заставки та інтерактивні сюрпризи.

## ✨ Основні функції

### 👨 Для Створювача (наприклад, чоловіка):
- **Щоденні заставки**: Завантаження 7 фото + текстів для кожного дня тижня
- **Створення челенджів**: Налаштування персональних викликів (30 днів, 7 днів тощо)
- **Гнучке планування**: Налаштування днів поступово або заздалегідь
- **Мультимедіа реакції**: Завантаження відео/аудіо для різних результатів
- **Календарне управління**: Візуальний календар з можливістю редагування
- **Аналітика**: Статистика успішності та прогресу

### 👩 Для Партнера (наприклад, дружини):
- **Щоденні заставки**: Отримання персональних фото та повідомлень
- **Проходження челенджів**: Введення відповідей та отримання реакцій
- **Календар прогресу**: Відстеження виконаних днів
- **Міні-ігри**: Квізи та розваги для зміцнення зв'язку
- **Віртуальні обійми**: Можливість надсилати емоції
- **Таймер зустрічей**: Відлік до наступної зустрічі

## 🎯 Як це працює

### Крок 1: Створення челенджу
1. Створювач завантажує 7 фото для щоденних заставок
2. Створює челендж з назвою та тривалістю
3. Налаштовує перший день (фото, повідомлення, питання, реакції)
4. Отримує код для поділитися з партнером

### Крок 2: Приєднання партнера
1. Партнер вводить код в застосунок
2. Отримує щоденні заставки о 09:00 (або налаштований час)
3. Проходить челендж дня
4. Отримує персоналізовані реакції

### Крок 3: Гнучке управління
- Створювач може налаштовувати дні поступово
- Редагувати майбутні дні в будь-який час
- Додавати сюрпризи та додаткові повідомлення
- Відстежувати прогрес партнера

## 🎨 Дизайн та UX

### Кольорова схема:
- **Рожевий/фіолетовий градієнт** - головний
- **Зелений** - успіх та виконання
- **Жовтий** - не виконано (але з підтримкою)
- **Червоний** - увага та сьогоднішній день

### Анімації:
- **Конфетті** - при успішному виконанні
- **Пульсація** - для сьогоднішнього дня
- **Плавні переходи** - між екранами
- **Hover ефекти** - для інтерактивних елементів

## 🔧 Встановлення та використання

1. Завантажте файли в папку проекту
2. Відкрийте `poru4-mobile-app.html` або `poru4-advanced.html` в браузері

   - Запустіть локальний сервер
   - Відкрийте через IP адресу пристрою
